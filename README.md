# 画室 · 学员档案与画材库存

画室业务管理系统：以「学员档案」为主，串起课程排期与画材领用两条从线，画材独立台账。靛青主题、顶部标签页导航、学员列表双击行打开右侧抽屉查看档案与排课。

## 启停

```bash
sh start.sh     # 构建并启动（mysql / backend / frontend）
sh stop.sh      # 停止
sh clean.sh     # 停止并清理数据卷
```

## 模块

- 学员档案：学号唯一、手机号校验、级别（少儿/成人/艺考）、状态（在读/休学/结业）
- 画材库存：名称唯一、库存≥0、类别（颜料/画笔/画布/工具）、停用不可领用
- 课程排期：依赖学员（在读才能排课）、同日期时段不重叠、待上课可取消/签到
- 课后成果记录：仅「已上课」可记录；一课次一份，支持草稿、已提交、已归档；草稿可只记点评，提交必须补齐作品主题、完成度和教师点评；已提交/已归档才计入已完成课程，归档后只读
- 领用记录：新建即扣库存、画材须「在库」、库存不足拦截

## 验收

完整链路会创建独立验收学员和课次，不改动种子排课、签到、库存数据：

```bash
sh start.sh --build
sh tests/acceptance-after-class.sh
```

既有数据库只增量执行 `mysql/migrations/20261007_01_add_after_class_record.sql`；全新镜像已在 `mysql/schema.sql` 中自动建表。

覆盖：正常草稿/提交/归档、待上课与已取消拦截、重复提交幂等、并发提交唯一结果、草稿删除、已完成课程过滤、学员状态变化/档案缺失的提交拦截。Docker 环境下会额外直接删除学员档案验证外键与业务校验。
